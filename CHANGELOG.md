# Changelog

## 1.0.0 — 2026-10-23

Первый выпуск.

- Подключение к серверу OpenCode в локальной сети и через Tailscale.
- Автоматическое переключение LAN ⇄ WAN с параллельной проверкой доступности.
- Ручное переключение и повторная проверка кнопками ⇄ и ⟳.
- Авторизация HTTP Basic, пароль в EncryptedSharedPreferences.
- Загрузка файлов, история навигации, edge-to-edge, локализация en/ru.
