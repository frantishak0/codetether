# Changelog

## 1.1.0 — 2026-10-23

- Подключение одним сканированием QR: `scripts/setup-server.sh` настраивает сервер и печатает код.
- Deep link `codetether://setup?d=…` — настройки можно передать ссылкой.
- Автообновление: приложение проверяет GitHub Releases и устанавливает новую версию.
- LAN теперь выбирается надёжнее (две попытки), плюс повторная проверка через 6 с после ухода на WAN.

## 1.0.0 — 2026-10-23

Первый выпуск.

- Подключение к серверу OpenCode в локальной сети и через Tailscale.
- Автоматическое переключение LAN ⇄ WAN с параллельной проверкой доступности.
- Ручное переключение и повторная проверка кнопками ⇄ и ⟳.
- Авторизация HTTP Basic, пароль в EncryptedSharedPreferences.
- Загрузка файлов, история навигации, edge-to-edge, локализация en/ru.
