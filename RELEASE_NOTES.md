## CodeTether 1.1.5

### Исправлено

- **«Чат ломается → сам чинится → через минуту опять ломается».**
  Приложение проверяло оба адреса одновременно и при малейшем сбое одной проверки
  переключалось между LAN и WAN, каждый раз перезагружая страницу. У каждого адреса
  свой кэш WebView, поэтому состояние «работает / не работает» чередовалось.

  Теперь логика такая:
  - если соединение по текущему адресу живо — приложение никуда не переключается
    (проверяется только этот адрес);
  - переход на другой адрес происходит только когда текущий реально недоступен;
  - находясь на WAN, приложение раз в минуту пытается вернуться в локальную сеть,
    и только тогда меняет адрес.

- **Полный сброс данных WebView (включая Service Worker) при смене версии сервера** —
  это устраняет «ClientError: Transport: Failed to fetch» после обновления OpenCode.
  Cookies не затрагиваются.

### Как обновить (важно)

Пункты меню приложения — это нативные элементы Android, они работают даже когда веб-страница
показывает ошибку:

**⚙ → Ещё → Проверить обновления → Скачать и установить**

Либо скачать APK вручную (ссылка всегда ведёт на последнюю версию):
`https://github.com/frantishak0/codetether/releases/latest/download/CodeTether-latest.apk`
