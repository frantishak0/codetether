## CodeTether 1.2.3

### Исправлено

- **Пропадали открытые вкладки чатов.** Сброс кэша при обновлении сервера/приложения удалял
  `Local Storage` WebView, а веб-интерфейс хранит там список открытых вкладок. Теперь сброс
  чистит только HTTP-кэш, Code Cache и Service Worker — вкладки сохраняются.

- **Сброс кэша теперь выполняется и при обновлении самого приложения**, а не только при смене
  версии OpenCode. Раньше после установки новой версии в кэше мог остаться старый интерфейс
  (`ClientError: Transport: Failed to fetch` с несуществующим `health-*.js`).

### Улучшено

- `largeHeap` для процесса: WebView с несколькими тяжёлыми чатами реже выгружается системой.

### Как обновить

`⚙ → Ещё → Проверить обновления`. После установки при первом запуске кэш очистится
автоматически, вкладки останутся на месте.
