## CodeTether 1.2.6

### Исправлено: старый интерфейс возвращался после перезапуска приложения

В 1.2.5 кэш чистился, и страница загружалась свежей — но только один раз. При следующем
открытии приложение грузило «чистый» адрес, и HTTP-кэш мог снова отдать старый `index.html`
с ссылками на исчезнувшие файлы (`health-CWDW51F7.js` → 404 → `Failed to fetch`).

Теперь **все** загрузки идут по адресу с версией сервера: `/?v=2.1.2`. Старый документ
физически не может быть отдан из кэша, потому что URL другой. При обновлении сервера
версия меняется → адрес меняется → загружается новый интерфейс.
