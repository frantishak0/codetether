## CodeTether 1.2.5

### Исправлено: старые файлы интерфейса оставались в HTTP-кэше

В 1.2.4 Service Worker чистился, но старые чанки маршрутов (`route-*.js`) продолжали
лежать в **дисковом HTTP-кэше WebView**. Файловое удаление блокирует процесс Chromium,
поэтому вкладка снова показывала:

```
ClientError: Transport: Failed to fetch
/_assets/health-CWDW51F7.js  (404)
Версия: 2.1.1
```

Теперь при сбросе:

1. вызывается `WebView.clearCache(true)` — штатный API, работает даже при занятых файлах;
2. на один цикл включается `LOAD_NO_CACHE`;
3. страница загружается по уникальному адресу `/?v=<время>`, поэтому берётся свежий
   `index.html`, а он ссылается на актуальные файлы;
4. после загрузки режим кэша возвращается в обычный.

Сброс выполняется автоматически после обновления приложения, а также по кнопке
**⚙ → Ещё → «Сбросить кэш (перезапуск)»**. Вкладки при этом сохраняются.
