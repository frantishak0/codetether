## CodeTether 1.2.4

### Исправлено: страница оставалась старой после обновления OpenCode

Раньше сброс кэша не срабатывал: файлы `Service Worker` и `CacheStorage` держал открытыми
процесс Chromium, поэтому удаление молча проваливалось, и вкладка продолжала показывать
старый интерфейс с ошибкой:

```
ClientError: Transport: Failed to fetch
/_assets/health-CWDW51F7.js  (404)
Версия: 2.1.1
```

Теперь кэш чистится **изнутри страницы через JavaScript**: снимается регистрация
Service Worker и удаляются все CacheStorage-кэши, после чего страница перезагружается.
Файловые блокировки этому не мешают.

### Проверено на устройстве (Lenovo Yoga Tab, Android 16)

- версия 1.2.4 установлена, интерфейс загружается актуальной версии;
- **вкладки сохраняются** после сброса кэша;
- сессия открывается, чат грузится без ошибок;
- уведомление о завершении задачи приходит (проверено сквозным тестом);
- сервис фонового наблюдения запускается и останавливается корректно.
