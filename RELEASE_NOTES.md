## CodeTether 1.0.0

Первый выпуск Android-клиента для OpenCode, работающего на вашем компьютере.

### Что умеет

- Подключение к серверу OpenCode **в локальной сети** и **через интернет (Tailscale)**.
- **Автоматическое переключение** LAN ⇄ WAN: приложение параллельно проверяет оба адреса
  и выбирает доступный, с приоритетом локальной сети.
- Ручное переключение (⇄) и повторная проверка (⟳).
- Авторизация HTTP Basic; пароль хранится в `EncryptedSharedPreferences`.
- Загрузка файлов из веб-интерфейса, история навигации по кнопке «Назад».
- Edge-to-edge, локализация: English, Русский.

### Установка

1. Скачайте `CodeTether-1.0.0.apk` и разрешите установку из неизвестных источников.
2. Подготовьте сервер:

   ```bash
   opencode service set hostname 0.0.0.0
   opencode service set password "ваш-пароль"
   opencode service start
   ```

3. Откройте приложение → **⚙** → укажите LAN-адрес (`http://192.168.x.x:49374`) и пароль.

Для работы вне дома поставьте Tailscale на компьютер и на устройство и укажите его адрес
(`http://100.x.y.z:49374`) в поле WAN.

### Файлы

- `CodeTether-1.0.0.apk` — подписанный APK для прямой установки.
- `CodeTether-1.0.0.aab` — Android App Bundle (для публикации в Google Play).
