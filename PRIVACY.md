# Политика конфиденциальности CodeTether

**Дата:** 23 октября 2026

CodeTether — клиент для самостоятельно размещённого сервера OpenCode. Приложение:

- **не собирает** персональные данные, телеметрию и статистику использования;
- **не содержит** рекламы и сторонних SDK аналитики;
- **не передаёт** данные третьим лицам;
- устанавливает сетевые соединения **только** с адресами, которые пользователь указал
  в настройках (сервер OpenCode в локальной сети или через Tailscale).

## Что хранится на устройстве

| Данные | Где | Зачем |
|---|---|---|
| Адреса LAN и WAN | `EncryptedSharedPreferences` | чтобы не вводить их повторно |
| Пароль сервера | `EncryptedSharedPreferences` | авторизация HTTP Basic |
| Cookies веб-интерфейса | хранилище WebView | сессия веб-интерфейса OpenCode |

Данные не покидают устройство и удаляются вместе с приложением (или кнопкой
«Очистить cookie» в настройках).

## Разрешения

- `INTERNET` — соединение с вашим сервером OpenCode.
- `ACCESS_NETWORK_STATE` — определение доступности сети для переключения LAN/WAN.
