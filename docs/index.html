CodeTether

Android-клиент для OpenCode, работающего на вашем компьютере. Локальная сеть и интернет через Tailscale — с автоматическим переключением.

Android 8.0+·302 КБ·без рекламы и аналитики·MIT
⬇ Скачать APK

Файл подписан: CN=CodeTether · все релизы

Установка за две минуты

1
На компьютере — одна команда настраивает сервер и печатает QR. 
curl -fsSL https://raw.githubusercontent.com/frantishak0/codetether/main/scripts/setup-server.sh | bash
Windows: powershell -ExecutionPolicy Bypass -File .\scripts\setup-server.ps1
2
На телефоне — установите APK и нажмите 📷, наведите камеру на QR. Адреса LAN/WAN и пароль подставятся сами.
3
Готово — дома приложение идёт напрямую по Wi-Fi, вне дома автоматически переключается на Tailscale.

Наведите камеру телефона, чтобы скачать APK

Возможности

Авто-переключение

Параллельная проверка обоих адресов: локальная сеть в приоритете, при её потере — мгновенный уход на Tailscale.

Подключение по QR

Скрипт настройки печатает код с адресами и паролем. Одно сканирование — и всё готово.

Автообновление

Приложение само проверяет новые релизы и предлагает обновиться.

Полный веб-интерфейс

Все сессии, проекты и инструменты OpenCode — как в браузере, но в удобном приложении.

Загрузка файлов

Прикрепляйте файлы к сообщениям прямо из системы Android.

Ничего лишнего

Без аналитики и рекламы. Пароль хранится в EncryptedSharedPreferences, соединения идут только к вашему серверу.

Linux / macOS49374setup-server.sh
Windows28894setup-server.ps1
WSL249374bash-скрипт + portproxy / mirrored networking

OpenCode внутри WSL2 сидит за NAT — телефон его не увидит напрямую. Включите networkingMode=mirrored в .wslconfig или пробросьте порт через netsh interface portproxy. Подробности — в README.
